# Locally hosted typography

No remote font service is used at runtime. Files are unmodified upstream assets under the accompanying SIL Open Font License notices. No font package was installed.

- Geist / Geist Mono: https://github.com/google/fonts/tree/main/ofl/geist and https://github.com/google/fonts/tree/main/ofl/geistmono
- Pretendard v1.3.9: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable

Geist supplies English/UI glyphs; Pretendard supplies Hangul and Korean Jamo through CSS unicode-range. Weights 400/500/600 are used; Geist Mono is limited to values and technical references. Tabular numerals align numbers. The platform wordmark is MOIRAI; no FIC logo asset is included or invented.
